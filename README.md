## Featured Projects

### 🛠️ Systems & Compilers

**[Arion](https://github.com/manuellthimoty/arion-language)** — A compiler and virtual machine built from scratch: lexer, parser, code generation, and a bytecode VM.

**[iciBOS](https://github.com/manuellthimoty/iciBOS)** — A 32-bit x86 operating system built from scratch in C and assembly for ITB's Operating Systems course: kernel, interrupts, memory management, file system, and a shell.

**[Mini SSO / Identity Provider](https://github.com/manuellthimoty/identity-auth-provider)** — A custom identity provider implementing OAuth 2.0 + OIDC with PKCE, opaque token sessions, and RabbitMQ message brokering in a Node.js/TypeScript monorepo.

### 🤖 AI / ML

**[Eigenfaces Face Recognition](https://github.com/manuellthimoty/eigenfaces)** — Face recognition from scratch with NumPy (PCA / eigen-decomposition), served via Flask with a Next.js frontend. Built in 2 days.

**[Connect-4 AI](https://github.com/manuellthimoty/connect-four)** — Connect-4 engine in GNU Prolog with minimax, alpha-beta pruning, transposition tables, and Zobrist hashing.

### 🔍 Algorithms in Practice


**[Spell Checker & Autocomplete](https://github.com/manuellthimoty/auto-key)** — Trie-based autocomplete with Levenshtein-distance correction and DP word segmentation; FastAPI backend, Next.js frontend.

**[Convex Hull Visualizer](https://github.com/manuellthimoty/the-great-wrap)** — Interactive visualizer comparing Graham Scan, Jarvis March, and QuickHull (Next.js, TypeScript, react-konva).

**[CPs](https://github.com/manuellthimoty/cpcpcpcp)** — Just me and my lovely c++.
